# Portfolio

Static portfolio website for Helmi & Leen.

## Publish with GitHub Pages

1. Create a GitHub repository named `Portfolio`.
2. Upload the contents of this folder to the repository root. Keep `index.html`, `styles.css`, `script.js`, and the `assets` folder together.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then save.
6. GitHub will show the published site URL in the Pages section after deployment finishes.

The video is stored at `assets/helmi-leen-intro.mp4`. The page and project images load from the `assets` folder, so do not upload only the HTML file.
